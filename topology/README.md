# 🌐 Network Topology

This directory contains the network diagram and the Cisco Packet Tracer simulation for the **Enterprise Network Defense-in-Depth** project.

## 📁 Files

| File | Description |
|---|---|
| `enterprise-network.pkt` | Editable Cisco Packet Tracer simulation. |
| `network-topology.png` | Visual overview of the corporate network architecture. |

## 🏗️ Network Overview

The topology includes departmental VLANs, a Layer 3 core switch, access switches, a border router, wireless connectivity, and a centralized Data Center with dedicated servers.
